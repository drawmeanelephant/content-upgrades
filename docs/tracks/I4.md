# Track I4: the beat-8 numbers card

Issue #101. `demo/card/` is new: `build.sh` writes `numbers.json` (every
value carries its source path plus the engine/scorer version) and renders
`numbers.png` (1920x1080) through `card.html` and a headless Chrome
screenshot (this ffmpeg has no drawtext — V0.md finding 4).

## Columns

Per the owner's freeze decision (I5.md): `mock (control)`,
`acp: devin summarizer`, and `Muse Wonder 1.0 via ACP (devin)`. No
spark/wonder/baseten — the sponsor API is out of scope, so those names
never appear.

## What's on the card

- repair converged on both corpora — the mock control row is a fresh
  `knap-mcp eval --backend mock` at build time (deterministic, offline,
  ~2.5 s for both corpora); the live columns come from the committed I2
  `.out` files. Exact-rate and mean-iter numbers ride as cell details.
- density/2 ratchet: cases ok /9 and the best climb per backend, parsed
  from the I3 raw files (`mock.txt`, `acp.txt`,
  `devin-wonder/ratchet.out`). Misses are model shortfall against the
  mock-tuned bar, not harness breakage.
- calls × mean slice for the repair-2nap and ratchet runs — the `calls:`
  instrumentation line in each `.out` file.
- k4o conformance 187/188, read from the pin-matched
  `eval/conformance/results/k4o-main-<pin>.json`, next to the
  base → #70 → #71 lineage headline (K3: never a main → #70 → #71
  progression).
- server LOC: `cat $(find knap-mcp/src -name '*.zig') | wc -l`.
- No token-cost numbers: ACP usage is agent-inclusive (~13.5k-token devin
  system prompt per call, LIVE.md finding 3), so tokens stay off the card
  entirely.

## For other lanes

- `numbers.png` is regenerated, never committed (`demo/card/.gitignore`
  follows demo's no-media rule); `numbers.json` is committed so the card's
  content is reviewable.
- The tape runs `card/build.sh` for real: keep its stdout ≤121
  columns/line and its runtime under ~5 s or beat 8 misses its 10 s
  target.
- On a k4o pin bump, the script looks for `k4o-main-<new pin>.json` and
  fails loudly if the conformance run for that pin does not exist
  (K3/K5's rerun procedure).
- `demo/run.sh` beat 8 calls `build.sh --json`, so `make demo` does not
  need Chrome.
