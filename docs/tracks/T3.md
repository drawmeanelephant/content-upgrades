# Track T3: real table headers in release-notes and reading-note

Status: done, PR open. k4o's `table` filter emits an empty header row and
pushes the data's first row into the body (knap-faithful). T2 already moved
the verdict receipts table past this; this lane applies the same pattern to
the other two table templates. Headers are now literal in the templates,
data rows are objects looped field by field, and k4o/dogbed render real
`<th>` cells.

## What landed

| File | What |
|---|---|
| `knap-mcp/templates/release-notes.knap` | `upgrade_matrix` block: literal `you are on | effort | downtime | should you bother` header + `---` delimiter, `{% for r in upgrade_matrix %}` rows |
| `knap-mcp/templates/reading-note.knap` | `aged` block: author-derived header `{{ byline | split:" " | last }}, {{ year }} | us, now | called it?` + `---` delimiter, looped rows |
| `knap-mcp/templates/shapes/release-notes.json` | `upgrade_matrix` -> `array<object>` with `fields` (all `{"type":"string"}`), `cells` dropped, role updated (header fixed in template) |
| `knap-mcp/templates/shapes/reading-note.json` | `aged` -> `array<object>` same treatment |
| `knap-mcp/data/release-notes.{sample,hallucinated}.json` | `upgrade_matrix` rows -> objects, header row dropped |
| `knap-mcp/data/reading-note.sample.json` | `aged` rows -> objects, header row dropped |
| `knap-mcp/eval/ratchet-mock.json` | `upgrade_matrix[+]`/`aged[+]` mock values -> objects, header rows dropped |
| `knap-mcp/eval/ratchet.json` | `adv-inert-markup` mock -> object form; `"effort":"**effort**"` still trips the inert guard |

One deviation from the brief: the header reads `byline`, not `author`.
`byline` is already `author ?? "Anonymous"`, so the sample still renders
`Forster, 1909`, and an anonymous note gets `Anonymous, <year>` instead of
the hole `, <year>`. Same filter chain (`split:" " | last`).
