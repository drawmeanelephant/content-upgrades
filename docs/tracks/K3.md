   80 corpus filters. That includes every SPEC demo filter, plus

   (or `gfm`) exits 1 with `invalid --format (expected markdown or oliver)`.
   knap-mcp's `textile` and `gfm` targets (`src/engine.zig`) would break if
   the k4o pin moved to `main`. This is a pin decision for the captain / K2:
   - stay on the #71 lineage: keeps textile/gfm, 48/188;
   - move to `main`: 181/188, markdown (plus `oliver`) only, drop or reroute
     the textile target. `main`'s CLI also differs (new flags, `batch`,
     `validate`, `help`).
3. **SPEC's cut-line.** On #71 the referential subset passes every corpus
   case that does not chain a filter outside the subset. The README has the
   per-filter table.
4. **I4 (numbers card):** read `results/summary.json` (`headline`) and
