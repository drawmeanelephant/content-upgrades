# E1: seeded-breakage corpus expansion

Lane E1 (Wave 0). Owner files: `knap-mcp/src/eval.zig`, `knap-mcp/eval/seeds.json`,
`knap-mcp/eval/seeds.2nap.json`, `knap-mcp/eval/templates/`, this note.

## What landed

- **No-op detection.** A non-control seed that renders clean before repair is
  reported as `no-op` and kept out of the convergence denominator. It is never
  counted as converged. Controls (class `control`) must render clean untouched,
  or they show as `BROKEN`. Both also print a line on stderr.
- **`wikilink-bad-arg` fixed.** The old break (`wikilink:"a|b"`) renders fine
  under the pinned k4o (`[[Ada|a|b]]`; wikilink takes any alias arg). It is now
  `{{ s.name | wikilink: }}`, which fails with `expected a filter argument after ':'`
  (class `empty-filter-arg`). The old 7/10 "converged" was really 6/9 breaks.
- **Template sources in the corpus.** A seed carries exactly one of
  `template_id` (shipped), `template` (inline text), or `template_path`
  (resolved against the corpus file's directory, then cwd, then the project
  root; `"@path"` data refs resolve the same way). No new CLI flags.
  `knap-mcp eval --corpus <file>` still works on old corpora.
- **Error classes.** Each seed has a `class`. An optional top-level
  `"classes"` array fixes the class-table order and rejects undeclared
  classes (a typo can't open a silent one-seed class). Defaults: a seed with
  no break and no class is a control; a mutated seed with no class is
  `unclassified`. Duplicate seed ids are rejected.
- **`exact` column.** For converged mutated seeds, the harness also renders the
  unbroken template and checks the repaired render is byte-identical. A patch
  that deletes the broken construct converges but is not exact. Every mutated
  seed's base template must render clean (stderr warning otherwise).
- **Output.** Per-seed table (adds `class` and `exact`), a per-class table
  (breaks, converged, rate, mean iters, exact, no-op), and a summary line.
  `mean iters` is now the mean over converged breaks (iterations to converge),
  not over all rows. The JSON report adds per-class stats and each row's
  `status`, `first_diag`, and `residual_diag`.
- **`eval/seeds.json`** grew from 10 to 25 seeds: all classes now appear on
  the demo templates (verdict, apparatus), plus 3 controls and a corpus-only
  template, `eval/templates/verdict-callout.knap`, that uses the k4o #71
  tranche (`{% set %}`, `??`, `callout` tuples) via `template_path`.
- **`eval/seeds.2nap.json`**: 187 seeds (185 breaks + 2 controls) from 2nap.

## Error classes

Classes name the mutation; the first k4o diagnostic depends on context and is
kept per row in the JSON report.

| class | mutation | typical k4o diagnostic | mock patch |
|---|---|---|---|
| unclosed-if | remove an `{% endif %}` | unclosed if block (missing '{% endif %}') | yes |
| unclosed-for | remove an `{% endfor %}` | unclosed for block (missing '{% endfor %}') | yes |
| unclosed-output | remove a ` }}` | unclosed '{{' tag (missing '}}'), or unexpected text in output tag | partial (see below) |
| unknown-filter | rename a filter to a plausible foreign name (`h2`→`head2`, `bold`→`strong`, `wikilink`→`wiki_link`) | no filter named "…" | yes (strips it) |
| dangling-pipe | drop a filter name, keep the `|` | expected a filter name after '\|' | truncated-line form only |
| orphan-endif | remove an `{% if … %}` opener | unexpected '{% endif/else/elseif %}' outside an if block | no |
| orphan-endfor | remove a `{% for … %}` opener | unexpected '{% endfor %}' outside a for block | no |
| mismatched-close | `{% endif %}`↔`{% endfor %}` | unexpected '{% endfor %}' outside a for block | no |
| unclosed-block-tag | `{% endif %}`→`{% endif` | unclosed '{%' tag (missing '%}') | no |
| unknown-tag | `{% elseif`→`{% elif`, or `{% endif %}`→`{% end %}` | unknown logic tag '…' | no |
| missing-value | drop an if condition / for iterable / set value / `??` fallback | expected a value | no |
| bad-filter-arg | arg on a no-arg filter (`bold:"x"`, `footnote:"1"`), or a variable in a callout tuple | filter '…' takes no arguments | no |
| missing-filter-arg | drop a required arg (`link`, `yaml_property`, `callout`) | filter '…' requires a … argument | no |
| empty-filter-arg | `filter:` with nothing after the colon | expected a filter argument after ':' | no |
| unclosed-tuple | drop the `)` of a callout tuple | unclosed '(' in filter argument | no |
| unclosed-comment | remove a `#}` | unclosed comment (missing '#}') | no |

## Why each NO class is NO under mock

Mock returns `null` for any diagnostic outside its canned table, so the loop
stops after one attempt. That covers every class from `orphan-endif` down:
orphan-endif, orphan-endfor, mismatched-close, unclosed-block-tag, unknown-tag,
missing-value, bad-filter-arg, missing-filter-arg, empty-filter-arg,
unclosed-tuple, unclosed-comment. These are expected NO until a real model
runs; they are the honest non-convergence signal.

NO rows inside the mock-patched classes:

- **unclosed-output (2/34 in 2nap, 1/1 in seeds.json).** k4o reports two
  shapes. When another token follows the cut tag it says
  `unexpected text in output tag`, which mock's `"output tag"` key matches.
  When the tag runs to EOF it says `unclosed '{{' tag (missing '}}')`, which
  mock does not match (29 seeds, plus 2nap's `err-unclosed-output`). Of the 5
  "unexpected text" seeds, 3 still fail because mock appends ` }}` at the end
  of the line, not where the tag ends, when more text or a second tag follows
  on that line (`loop-nested`, `loop-values`, `unicode-data`).
- **dangling-pipe (0/22 in 2nap, 1/2 in seeds.json).** The mutation leaves
  `{{ x | }}`. Mock's patch only handles a `{{` line that ends in a bare
  `|` (the shape of the original `dangling-filter` seed, which still
  converges). `bare-dangling-pipe` in seeds.json is the `| }}` shape.
- **unclosed-if (9/10).** `loop-values/unclosed-if` drops an `endif` that sits
  inside a for loop, so k4o reports `unexpected '{% endfor %}' inside an if
  block` instead of an unclosed if.
- **unclosed-for (1/2 in seeds.json).** `unclosed-for-sources` drops the
  sources `endfor` inside `{% if sources %}`; k4o reports
  `unexpected '{% endif %}' inside a for block`.
- **unknown-filter (22/23).** `filter-link-basic`: stripping `| url` leaves
  the orphaned `:"https://example.com/"`, so the next diagnostic is
  `unexpected text in output tag` and mock finds no unbalanced line.

Why `exact` is low under mock: it strips unknown filters instead of restoring
the intended one (the heading/bold/list markup is gone), and it closes
unclosed blocks at EOF, which pulls the trailing newline inside the block.
The 4 exact rows are if/else seeds whose taken branch is not the one that
absorbed that newline.

```python
#!/usr/bin/env python3
"""Generate knap-mcp/eval/seeds.2nap.json from 2nap's fixture corpus.

Usage: gen_2nap_seeds.py <2nap-root> <knap-mcp-root>

Each 2nap output triple (template + data + expected textile) is mutated
through the pinned error classes; 2nap's template-error cases are added
as pre-broken seeds. Examples are copied to eval/templates/2nap/ and
referenced by template_path; fixtures are inlined.
"""
import json, os, re, shutil, subprocess, sys

NAP, KM = sys.argv[1], sys.argv[2]
K4O = os.environ["KNAP_K4O_PATH"]

CLASSES = ["unclosed-if", "unclosed-for", "unclosed-output", "unknown-filter", "dangling-pipe",
           "orphan-endif", "orphan-endfor", "mismatched-close", "unclosed-block-tag", "unknown-tag",
           "missing-value", "bad-filter-arg", "missing-filter-arg", "empty-filter-arg", "unclosed-tuple",
           "unclosed-comment"]

UNKNOWN_ALIAS = {  # plausible names borrowed from other template/markup vocabularies
    "h1": "head1", "h2": "head2", "h3": "head3", "h4": "head4", "h5": "head5", "h6": "head6",
    "bold": "strong", "italic": "em", "list": "bullets", "numbered": "ordered",
    "table": "grid", "code": "monospace", "codeblock": "fence", "blockquote": "quote",
    "link": "url",
}
NOARG = {"h1", "h2", "h3", "h4", "h5", "h6", "bold", "italic", "list", "numbered",
         "table", "code", "codeblock", "blockquote"}
NEEDARG = {"link"}

FILTER_RE = re.compile(r'\|\s*([a-z_][a-z0-9_]*)(:("[^"]*"|[^\s|}]+))?(?=\s*(\||}}))')
IF_RE = re.compile(r'\{% if ([^%]+?) %\}')
FOR_RE = re.compile(r'\{% for (\w+) in ([^%]+?) %\}')
OUT_RE = re.compile(r'\{\{[^}]*\}\}')
COMMENT_RE = re.compile(r'\{#.*?#\}', re.S)

# 2nap's error cases ship without data; a correct repair still has to render,
# so loops and tags get the minimal data they need.
ERROR_DATA = {
    "err-bad-args-extra": {"t": "watch out"},
    "err-bad-args-link-missing": {"t": "Example"},
    "err-unclosed-for": {"xs": ["a", "b"]},
    "err-unclosed-if": {"x": True},
    "err-unclosed-output": {"title": "Hello"},
    "err-unknown-filter": {"title": "Hello"},
}

ERROR_CASES = {  # 2nap error case -> class; the rest are skipped (see SKIPPED_ERRORS)
    "err-bad-args-extra": "bad-filter-arg",
    "err-bad-args-link-missing": "missing-filter-arg",
    "err-if-missing-value": "missing-value",
    "err-stray-endif": "orphan-endif",
    "err-unclosed-comment": "unclosed-comment",
    "err-unclosed-for": "unclosed-for",
    "err-unclosed-if": "unclosed-if",
    "err-unclosed-output": "unclosed-output",
    "err-unknown-filter": "unknown-filter",
}
SKIPPED_ERRORS = {
    "err-deep-list": "data-shape render error (template is correct; fix belongs in data). Pinned k4o also renders 4-level lists, so it no longer errors",
    "err-loop-nonarray": "data-shape render error (template is correct; fix belongs in data)",
    "err-multiline-bold": "data-shape render error (template is correct; fix belongs in data)",
    "err-nonarray-list": "data-shape render error (template is correct; fix belongs in data)",
    "err-ragged-table": "data-shape render error (template is correct; fix belongs in data)",
    "err-nesting-too-deep": "degenerate 64-level nesting stress case with no plausible intended template",
    "bad-data.json": "invalid JSON data file, not a template error",
}


def occ(text, find, pos):
    """Occurrence index of `find` at byte position `pos`."""
    n, at = 0, 0
    while True:
        hit = text.find(find, at)
        assert hit != -1
        if hit == pos:
            return n
        n, at = n + 1, hit + len(find)


def brk(text, find, replace, pos=None):
    pos = first(text, find) if pos is None else pos
    if pos == -1:
        return None
    b = {"kind": "remove" if replace == "" else "replace", "find": find}
    if replace != "":
        b["replace"] = replace
    o = occ(text, find, pos)
    if o:
        b["occurrence"] = o
    return b


def live(text):
    """Predicate: is byte position outside every {# comment #}?"""
    spans = [m.span() for m in COMMENT_RE.finditer(text)]
    return lambda pos: not any(a <= pos < b for a, b in spans)


def first(text, find):
    """First occurrence of `find` outside comments, or -1."""
    ok, at = live(text), 0
    while (hit := text.find(find, at)) != -1:
        if ok(hit):
            return hit
        at = hit + len(find)
    return -1


def search(rx, text):
    ok = live(text)
    return next((m for m in rx.finditer(text) if ok(m.start())), None)


def filters(text):
    """(name, full_token, start, tag) for each filter application in live output tags."""
    out, ok = [], live(text)
    for tag in OUT_RE.finditer(text):
        if not ok(tag.start()):
            continue
        for m in FILTER_RE.finditer(tag.group(0)):
            out.append((m.group(1), m.group(0), tag.start() + m.start(), tag))
    return out


def mutations(t):
    m = []
    has = lambda s: first(t, s) != -1
    if has("{% endif %}"):
        m.append(("unclosed-if", brk(t, "{% endif %}", "")))
    if has("{% endfor %}"):
        m.append(("unclosed-for", brk(t, "{% endfor %}", "")))
    if has(" }}"):
        m.append(("unclosed-output", brk(t, " }}", "")))
    fs = filters(t)
    if fs:
        name, tok, pos, _ = fs[0]
        alias = UNKNOWN_ALIAS.get(name)
        if alias and t.startswith(f"| {name}", pos):
            m.append(("unknown-filter", brk(t, f"| {name}", f"| {alias}", pos)))
        # dangling pipe: drop the last filter name of the first filtered tag
        tag = fs[0][3]
        last = [f for f in fs if f[3] is tag][-1]
        tail = t[last[2]:tag.end()]          # e.g. '| h2 }}'
        m.append(("dangling-pipe", brk(t, tail, "| }}", last[2])))
    noarg = [f for f in fs if f[0] in NOARG and ":" not in f[1]]
    if noarg:
        name, tok, pos, tag = noarg[0]
        tail = t[pos:tag.end()]
        m.append(("bad-filter-arg", brk(t, tail, tail.replace(tok, tok + ':"x"', 1), pos)))
    needarg = [f for f in fs if f[0] in NEEDARG and ":" in f[1]]
    if needarg:
        name, tok, pos, _ = needarg[0]
        m.append(("missing-filter-arg", brk(t, tok, f"| {name}", pos)))
        m.append(("empty-filter-arg", brk(t, tok, f"| {name}:", pos)))
    ifm = search(IF_RE, t)
    form = search(FOR_RE, t)
    if ifm:
        m.append(("orphan-endif", brk(t, ifm.group(0), "", ifm.start())))
    if form:
        m.append(("orphan-endfor", brk(t, form.group(0), "", form.start())))
    if "#}" in t:
        m.append(("unclosed-comment", brk(t, "#}", "", t.find("#}"))))
    if ifm:
        m.append(("missing-value", brk(t, ifm.group(0), "{% if %}", ifm.start())))
    elif form:
        m.append(("missing-value", brk(t, form.group(0), "{%% for %s in %%}" % form.group(1), form.start())))
    closers = [(first(t, c), c) for c in ("{% endif %}", "{% endfor %}") if has(c)]
    if closers:
        pos, c = min(closers)
        m.append(("unclosed-block-tag", brk(t, c, c[:-3], pos)))
    if has("{% endif %}"):
        m.append(("mismatched-close", brk(t, "{% endif %}", "{% endfor %}")))
    elif has("{% endfor %}"):
        m.append(("mismatched-close", brk(t, "{% endfor %}", "{% endif %}")))
    if has("{% elseif "):
        m.append(("unknown-tag", brk(t, "{% elseif ", "{% elif ")))
    elif has("{% endif %}"):
        m.append(("unknown-tag", brk(t, "{% endif %}", "{% end %}")))
    elif has("{% endfor %}"):
        m.append(("unknown-tag", brk(t, "{% endfor %}", "{% end %}")))
    return [(c, b) for c, b in m if b is not None]


def k4o_textile_ok(tpl, data, want):
    r = subprocess.run([K4O, "render", tpl, "--data", data, "--format", "textile"], capture_output=True)
    return r.returncode == 0 and r.stdout == open(want, "rb").read()


def main():
    seeds, skipped, sources = [], [], 0
    fx = os.path.join(NAP, "fixtures")
    ex_dst = os.path.join(KM, "eval", "templates", "2nap")
    os.makedirs(ex_dst, exist_ok=True)

    triples = [("fixtures", os.path.join(fx, f[:-5])) for f in sorted(os.listdir(fx)) if f.endswith(".knap")]
    triples += [("examples", os.path.join(NAP, "examples", f[:-5]))
                for f in sorted(os.listdir(os.path.join(NAP, "examples"))) if f.endswith(".knap")]
    for kind, base in triples:
        name = os.path.basename(base)
        if not k4o_textile_ok(base + ".knap", base + ".json", base + ".textile"):
            skipped.append({"source": f"{kind}/{name}", "reason": "pinned k4o does not reproduce 2nap's expected textile"})
            continue
        sources += 1
        text = open(base + ".knap").read()
        data = json.load(open(base + ".json"))
        if kind == "examples":
            shutil.copy(base + ".knap", os.path.join(ex_dst, name + ".knap"))
            shutil.copy(base + ".json", os.path.join(ex_dst, name + ".json"))
            src = {"template_path": f"templates/2nap/{name}.knap", "data": f"@templates/2nap/{name}.json"}
            sid = f"ex-{name}"
        else:
            src = {"template": text, "data": data}
            sid = name
        for cls, b in mutations(text):
            assert cls in CLASSES, cls
            seeds.append({"id": f"{sid}/{cls}", "class": cls, "source": f"2nap:{kind}/{name}", **src, "break": b})
        if name in ("var-plain", "heading"):
            seeds.append({"id": f"{sid}/control", "class": "control", "source": f"2nap:{kind}/{name}", **src})

    ed = os.path.join(fx, "errors")
    for case, cls in ERROR_CASES.items():
        text = open(os.path.join(ed, case + ".knap")).read()
        dpath = os.path.join(ed, case + ".json")
        data = json.load(open(dpath)) if os.path.exists(dpath) else ERROR_DATA.get(case, {})
        seeds.append({"id": case, "class": cls, "source": f"2nap:fixtures/errors/{case}",
                      "template": text, "data": data, "break": {"kind": "none"}})

    rev = subprocess.run(["git", "-C", NAP, "rev-parse", "--short", "HEAD"], capture_output=True, text=True).stdout.strip()
```
