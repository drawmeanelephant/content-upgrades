# Track I1: end-to-end `make demo`

Owner files: `demo/run.sh`, the `demo` target in the root `Makefile`, a pointer
paragraph in `demo/storyboard.md`, and this note.

## What landed

- `make demo` (depends on `all engines`) runs `demo/run.sh`. The script runs
  every storyboard beat in order as one scripted terminal session, using the
  mock backend, the pinned engines, a fresh temp `KNAP_MCP_HOME`, and a scratch
  workdir whose symlinks keep on-screen paths short (`data/`, `templates/`,
  `out/`). There are no live model calls and no network.
- Beats, each with a `######## beat N: ...` header and `$ command` prompt lines:
  1. cold open: `density` on the generic fixture (3.7)
  2. data only: MCP `tools/list` over stdio, the verdict shape's field names,
     the drafted values, `validate` ok
  3. repair: seeded unclosed `{% if %}` -> diagnostic -> `repair` converges in 1
     iteration -> `cmp` shows it is byte-identical to the clean render
  4. the doc: markdown render -> `format-check` (no warnings) -> `density` (77.5)
     with its per-signal breakdown
  4b. ratchet: `release-notes.min.json` -> 4 accepted steps, 44.5 -> 71.3 (stops
     at the ceiling); `density` on the ratcheted doc confirms the score
  5. boris catch: one invented source -> `publish-check` fails with
     `EREFERENCEMISSING` (exit 1, asserted) and the offending line; the real
     data passes
  6. voice: `knap-mcp voice` in mild, spicy and feral -> markdown and html
     renders -> `structhash` gives one hash per target across original + 3
     tones (asserted, so the run fails if a tone moves the layout) -> `diff`
     mild vs feral
  7. one source: verdict to markdown, oliver and html, plus apparatus html;
     `format-check` on the oliver doc; `grep -c '<script'` finds none
  8. numbers: both mock eval convergence lines, and the line count of `src/`
- The demo fails if any command's exit status is not the one the beat expects;
  a FAIL line names the beat. The expected failures (`diff`, the seeded
  `validate`, the hallucinated `publish-check`, `grep` with no matches) are
  asserted as exit 1.
- Output goes to `demo/out/demo/` (gitignored): `transcript.txt`, plus
  `artifacts/` with every rendered doc, the voiced data, the ratchet JSON and
  the structhash lists (23 files). Run-to-run noise is normalized: doc ids
  become `doc-<id>` and the scratch dir becomes `.`, so a second run on the same
  commit prints the same bytes. Each run compares its transcript with the
  previous one and prints `identical` or `differs`. This is reported, not a
  failure: a template edit is supposed to change the transcript.
- `DEMO_OUT` moves the output dir (useful as a CI artifact path).

## Notes for other lanes

- **boris:** `publish-check` needs the `boris` binary (`KNAP_BORIS_PATH`, else
  `PATH`). Without it, beat 5 prints `SKIPPED` and the summary row says
  `SKIPPED (no boris)`; the run still exits 0. CI has no boris today, so adding
  `make demo` to `ci.yml` (CI lane) would skip that beat until boris is
  installed there.
- **Hallucinated data:** beat 5 derives the bad doc from `verdict.sample.json`
  plus one invented source, on screen, the same way `demo/lib/env.sh` and
  `boris-site/selftest.sh` do. `knap-mcp/data/verdict.hallucinated.json` is
  stale: it predates the current verdict shape (old frontmatter block, array-row
  receipts, list footnotes). It still renders and still trips publish-check,
  but whoever owns `data/` should regenerate it from the sample.
- **Feral `!` hazard (CAPTAIN.md):** the demo voices only the verdict. Feral
  `summary` ends in `!`, but no footnote marker follows it in `verdict.knap`, and
  the html structhash assertion would catch the hazard if one did.
- **Tapes:** the vhs tapes are unchanged. Beats 4b, 5 and 6 still show their
  placeholder or stand-in commands (slate, `stage-check.sh`, `demo_seed_voice`).
  The real commands are now in `demo/run.sh` and can be copied into the tapes
  when V0 or the human re-records.
- **Conformance:** `knap-mcp/eval/conformance/results/` only has results for k4o
  `bdfb838`, not the current pin `aeba163`, so beat 8 leaves conformance out
  rather than quote a stale number.
