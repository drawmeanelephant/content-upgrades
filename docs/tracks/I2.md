## Notes for other lanes

- **Cost/spend:** no API key, no metered spend — each call is a `devin acp`
  session (~5–10 s). The summarizer column's `tokens:` reads 0s because that
  agent returns no `usage` object on `session/prompt`; the devin agent does,
  so the Muse Wonder column's token lines are real and dominated by the
  agent's ~13.5k-token system prompt per call.
- **Exact match** means byte-identical to the unbroken render; semantically
  correct but differently-styled patches count as converged, not exact.
- The eval's JSON report lands in the per-run `KNAP_MCP_HOME` store
  (`knap://docs/doc-<ns>-<id>`) and is not retained; the durable artifacts
  are the `.out`/`.err` files cited above.
